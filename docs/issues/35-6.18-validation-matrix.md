# [Validation] 6.18 functional + performance matrix (Stage 12)
labels: porting, validation, testing
---

Stage 12. The acceptance gate before the 7.1 rebase (live #13). Correctness first,
perf second.
Roadmap: [Stage 12 row](../porting-roadmap.md#14-stage-plan-reconciliation).

## Functional matrix
- [ ] 100 consecutive boots, no regressions / IRQ storms.
- [ ] `stress-ng` (CPU/mem/IO), memtest pass.
- [ ] 4-drive concurrent I/O.
- [ ] RAID create / degrade / rebuild / scrub (baseline #32, then accel #11/#23).
- [ ] 1GbE and 10G link; SFP+ optical AND DAC modules.
- [ ] USB mass-storage; SPI-NOR reads (no writes).
- [ ] Fans (adt7475) + temp (al_thermal); watchdog (sp805); RTC (s35390a).
- [ ] Bay LEDs (SGPO); crypto KATs (if driver present); PCIe AER clean.

## Performance (after correctness)
- [ ] Record 1G/10G throughput, RAID rebuild rate, IO latency — with date/commit
  and conditions so staleness is visible (docs, not code comments).

## Acceptance criteria
- [ ] Every functional row passes; failures filed as their own issues.
- [ ] Perf recorded as the 6.18 baseline for the 7.1 comparison (live #13).

Depends: all Phase-1 bring-up + #32.
