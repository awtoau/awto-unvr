# Issue drafts — transient staging

- `docs/issues/` is **transient staging** for GitHub issues, nothing more.
- Once a draft is filed, it is **deleted** — GitHub is the record. No local mirror,
  no per-issue numbering archive (that is duplicate info).
- Unique analysis/findings live in `docs/` (e.g. `ddr-config-reverse.md`,
  `unvr-access-research.md`), never here.
- Live issues: `gh issue list --repo awtoau/awto-unvr --state all`.
