# S-35390A — ABLIC (Seiko) real-time clock

- **Part:** **S-35390A** (ABLIC / formerly Seiko Instruments, SII).
- **Function:** battery-backed real-time clock.
- **Confirmed:** dmesg `rtc-s35390a 1-0030`, DT `sii,s35390a @ i2c 0x30`. ✅ live.

## Key specs

- **Interface:** 2-wire (I²C-compatible), address **0x30**.
- **Voltage: 1.3–5.5 V** operation — wide range covers main rail and backup battery.
- **Current:** ~0.25 µA typ at timekeeping (long backup life).
- **Clock source:** external 32.768 kHz crystal.
- **Features:** alarm + `INT` output, digital freq. correction, user free registers (usable as backup RAM).
- **Package:** 8-pin (SNT / SOP).

## How it connects here

- **Bus:** on-SoC DesignWare I²C, addr 0x30 — [hardware.md#mmio-and-address-map](../hardware.md#mmio-and-address-map).
- **Driver:** `rtc-s35390a` (mainline).

## RE / repurpose notes

- **Backup power:** find its Vbat source on-board (coin cell or supercap). If the clock loses time across full power-off, the backup source is dead/absent — check before blaming the driver.
- 32.768 kHz crystal nearby; digital correction registers exist if drift is an issue.
- Free user registers survive main-power loss (if backup present) — usable for small persistent flags.
