# AR8031 — Qualcomm/Atheros 1G Ethernet PHY

- **Part:** Qualcomm **Atheros AR8031** ("Arctic" family; siblings AR8033/AR8035).
- **Function:** 10/100/1000 PHY for the **1G RJ45** port (enp0s1 / al_eth1, RGMII).
- **Confirmed:** dmesg `driver Atheros 8031`, `phy exist Yes, addr 4, mdio 1000 kHz, SFP No, media 1`. ✅ live. (The 10G SFP+ port has **no** PHY — that is an optic, see [sfp-optic.md](sfp-optic.md).)

## Key specs

- **Interface:** RGMII **or** SGMII to MAC; copper line side. On this board: **RGMII**.
- **Speeds:** 10/100/1000 Mbps.
- **MDIO address:** 4. MDIO clock 1000 kHz.
- **Voltage:** integrated LDO for the 1.0 V core; RGMII I/O rail selectable 1.5 / 1.8 / 2.5 V (VDDIO). Confirm the board's RGMII rail if level-shifting.
- **Clock:** 25 MHz reference (crystal); provides a 125 MHz CLK_25M output option.
- **Package:** 48-pin QFN (typical for AR8031).

## How it connects here

- **MAC:** on-SoC al_eth port 1 (`1c36:0001`), RGMII. PHY on the SoC MDIO bus at addr 4.
- **Driver:** mainline **`at803x`** — **needs `CONFIG_REGULATOR=y`** (probe fails without it). Vendor kernel calls it "Atheros 8031".
- Board-info line (all boots): `phy[4]:supported 2ef adv 2ef`; RJ45 negotiated 100 Mbps/Full at capture.

## RE / repurpose notes

- Standard clause-22/45 MDIO — readable with any MDIO master once the PHY is powered and out of reset.
- If reusing on a mainline kernel: `at803x` binds it; watch the regulator dependency above.
- RGMII TX/RX delay (internal vs board trace) is a common bring-up gotcha — the AR8031 has configurable RGMII delay registers; match to what the vendor DT/al_eth sets.
