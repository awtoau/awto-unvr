# AR8033 — Qualcomm/Atheros 1G Ethernet PHY

- **Part:** Qualcomm **Atheros AR8033** ("Arctic" family; siblings AR8031/AR8035).
  Board marking **`AR8033-AL1A`** at **U51** (photo `../photos/20260816_225423.jpg`).
- **Driver reports "8031":** Linux `at803x` prints `driver Atheros 8031` because
  **AR8031 and AR8033 share PHY ID `0x004dd074`** — same silicon family, one driver.
  So "chip = AR8033, driver-label = 8031" is not a contradiction. (Our earlier doc
  was named ar8031 after the driver string; the physical part is AR8033.)
- **Function:** 10/100/1000 PHY for the **1G RJ45** port (enp0s1 / al_eth1, RGMII).
- **Confirmed:** dmesg `driver Atheros 8031`, `phy exist Yes, addr 4, mdio 1000 kHz,
  SFP No, media 1` ✅ live; marking `AR8033-AL1A` ✅ photo. (The 10G SFP+ port has
  **no** PHY — it's an optic, see [sfp-optic.md](sfp-optic.md).)

## Key specs

- **Interface:** RGMII **or** SGMII to MAC; copper line side. On this board: **RGMII**.
- **Speeds:** 10/100/1000 Mbps. **MDIO address:** 4, clock 1000 kHz.
- **Voltage:** integrated LDO for the 1.0 V core; RGMII I/O rail selectable
  1.5 / 1.8 / 2.5 V (VDDIO). AR8033 is the SyncE-capable sibling of AR8031.
- **Clock:** 25 MHz reference (crystal); 125 MHz CLK output option.
- **Package:** 48-pin QFN.

## How it connects here

- **MAC:** on-SoC al_eth port 1 (`1c36:0001`), RGMII. PHY on the SoC MDIO bus, addr 4.
- **Driver:** mainline **`at803x`** — **needs `CONFIG_REGULATOR=y`** (probe fails
  without it). Covers AR8031/8033/8035.
- Board-info line (all boots): `phy[4]:supported 2ef adv 2ef`.

## RE / repurpose notes

- Standard clause-22/45 MDIO — readable with any MDIO master once powered + out of reset.
- Mainline: `at803x` binds it; watch the regulator dependency.
- RGMII TX/RX delay (internal vs board trace) is a common bring-up gotcha — AR8033
  has configurable RGMII delay registers; match what the vendor DT/al_eth sets.
