# ADT7475 — thermal monitor + fan controller

- **Part:** **ADT7475** (Analog Devices "dBCool"; also produced by onsemi).
- **Function:** temperature monitoring + PWM fan control (3 chassis fans).
- **Confirmed:** hwmon `adt7475 4-002e` rev 1, DT `adi,adt7475 @ i2c 0x2e`. ✅ live.

## Key specs

- **Fans:** controls/monitors up to 4 fans; **3 PWM outputs** (PWM1–3) + tach inputs.
- **Temp sensors:** 1 on-chip + 2 remote (diode) = 3 zones. Matches U-Boot `dtt_get_temp[0..2]`.
- **Interface:** I²C / SMBus, address **0x2e**.
- **Voltage:** VCC 3.0–5.5 V (board 3.3 V domain).
- **Drive:** high- and low-frequency PWM; automatic fan-speed control from temperature.
- **Package:** 16-pin QSOP / TSSOP.

## How it connects here

- **Bus:** on-SoC DesignWare I²C, addr 0x2e (bus 4 per `adt7475 4-002e`) — [hardware.md#mmio-and-address-map](../hardware.md#mmio-and-address-map).
- **Driver:** `adt7475` (mainline hwmon). Reports `fan4 pwm2` mapping, rev 1.
- **Role:** the 3 chassis fans. Likely the source of U-Boot's `dtt_get_temp[0..2]` (cold-boot 103/99/101) — mapping to the three sensors is an open question in [hardware.md](../hardware.md#open-questions).

## RE / repurpose notes

- **Fan control regs** (for repurpose): PWM duty at `0x30–0x32`; PWM config `0x5C–0x5E`; temp readings `0x25–0x27`; tach at `0x28–0x2F`. Full map in the datasheet.
- Under Linux: `hwmon` exposes `pwm1..3`, `pwm*_enable` (set to 1 for manual/full), `fan1..*_input`, `temp1..3_input`. Set `pwm*_enable=1` and `pwm*=255` to force full fans for a stress/thermal test.
- 3 remote temp diodes — verify which physical location each maps to before trusting a zone reading.
