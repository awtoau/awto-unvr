# AL-324 — Annapurna Labs Alpine V2 SoC (U1)

- **Part:** Annapurna Labs (Amazon) **AL-324**, Alpine V2 family.
- **Function:** main SoC — CPU, DRAM controller, all integrated I/O.
- **Confirmed:** U-Boot `Device ID = a324`; EEPROM `Revision ID = 39`, `Device Info: v2sil-39-rc1`. ✅ live.

## Key specs

- **CPU:** 4× ARM Cortex-A57, ARMv8-A, up to ~1.7 GHz. MIDR `0x411fd073` = **r1p3** (part `0xd07`). All cores start at EL2.
- **Interrupt:** GIC-v3. **Timer:** ARMv8 generic, 58.33 MHz. **PSCI:** v0.2 (SMC).
- **DRAM controller:** DDR4, 2 banks (see [dram-ddr4.md](dram-ddr4.md)).
- **Process/package:** BGA, soldered. No public package/pinout (NDA).
- **Voltage:** core rails SoC-internal (not board-programmable). Peripheral I/O rails 1.8 V (NOR/NAND/most I2C devices are 1.8 V — see per-chip docs).

## RE / repurpose notes

- Secure boot: preboot verifies an RSA modulus hash from eFuse @ `0xfd89608c` (32 B). See [preboot-decompile.md](../preboot-decompile.md) §RSA.
- No JTAG pinout confirmed on this board (open question).
- Reset type reported as `Boot: warm` in banner; kernel cmdline is `reboot=warm reboot=warm` (see hardware.md correction note — **not** `reboot=cold`).
