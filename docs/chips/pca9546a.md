# PCA9546A — 4-channel I2C mux

- **Part:** **PCA9546A** (board part marked PCA9546; NXP original).
- **Function:** 1-to-4 I²C bus switch — fans out the SoC I²C to 4 downstream segments.
- **Confirmed:** i2c-devices `pca9546 @ 0x71`, driver `pca954x`, 4 muxed busses. ✅ live.

## Key specs

- **Switch:** 1-of-4 bidirectional translating channels, any combination selectable via a control register.
- **Interface:** I²C / SMBus.
- **Voltage:** 1.65–5.5 V (TI second-source range; NXP 2.3–5.5 V). Board rail is the 1.8 V I²C domain.
- **Reset:** active-LOW `RESET` input. 3 address pins → up to 8 muxes on a bus.
- **Package:** 16-pin TSSOP / SOIC / QFN.

## How it connects here

- **Bus:** on-SoC DesignWare I²C @ 0x71 — [hardware.md#mmio-and-address-map](../hardware.md#mmio-and-address-map). U-Boot `Setting bus to 4` at boot → ≥5 logical buses.
- **Driver:** `pca954x` (mainline).
- **Role:** expands the I²C tree; downstream segments likely carry the SPD (0x57), and possibly the SFP module EEPROM (see [sfp-optic.md](sfp-optic.md)) — segment map not fully traced.

## RE / repurpose notes

- Control register: 1 byte, bits[3:0] = channel enable. Read/write at 0x71 to select segments.
- Trace the 4 segments (read each with the channel enabled) to complete the I²C map — the SPD and SFP EEPROM live behind it.
