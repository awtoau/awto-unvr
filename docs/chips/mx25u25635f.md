# MX25U25635F — Macronix SPI-NOR boot flash

- **Part:** Macronix **MX25U25635F** (MX25U series).
- **Function:** boot flash. Holds the whole boot chain: preboot + U-Boot + env + Factory + EEPROM + recovery + config (mtd5–mtd12).
- **Confirmed:** U-Boot `SF: Detected MX25U25635F`, dmesg `found mx25u25635f`. ✅ live.

## Key specs

- **Capacity:** 256 Mbit = **32 MiB**.
- **Voltage: 1.8 V** (VCC 1.65–2.0 V) — **MX25U = 1.8 V series**. Matters for programming (see below).
- **Interface:** SPI, 1/2/4-bit (SPI / QPI). Up to 133 MHz (some modes to 166 MHz).
- **Program/erase:** page program 256 B; sector erase 4 KiB; block erase 32 KiB / 64 KiB.
- **Package:** typ. 8-pin SOP-8 / WSON-8 / USON (208-mil SOP on this class of board — confirm by silkscreen).
- **Secured OTP:** 4 Kbit one-time-programmable region.

## How it connects here

- **Bus:** on-SoC DesignWare SPI (spi0) @ `0xfd882000` — [hardware.md#mmio-and-address-map](../hardware.md#mmio-and-address-map).
- **Driver:** `spi-dw` + `m25p80` (mainline); U-Boot `sf`.
- **Role / layout:** boot chain + partition table in [nor-boot-chain.md](../nor-boot-chain.md). NOR carries mtd5–mtd12; NAND carries mtd0–4.

## RE / repurpose notes

- **Programming voltage = 1.8 V.** A 3.3 V SPI programmer will not read/write it safely — use a 1.8 V-capable programmer or a 1.8 V level-shifting adapter (e.g. flashrom + 1.8 V clip/socket). Applying 3.3 V VCC risks the part.
- **SOP-8 pinout** (standard MX25U, quad):
  1 CS# · 2 SO/IO1 · 3 WP#/IO2 · 4 GND · 5 SI/IO0 · 6 SCLK · 7 HOLD#(RESET#)/IO3 · 8 VCC(1.8 V)
- In-circuit reading contends with the SoC — hold the SoC in reset or lift VCC; a SOP-8 test clip on the chip is the usual route.
- JEDEC ID `C2 25 39` (Macronix / MX25U256 family) — for programmer auto-detect.
